# XHY Terminal

个人总终端：加密资产、比特币价格警报与快速出境，并提供 Windows CMD 界面。饮食日记已从网页移除，代码与日记数据仍保留在 `apps/diet/`，CMD 客户端仍可查看和修改。

## 代码结构

- 根目录及 `frontend/`：统一网页、深浅主题、北京/GMT/丹佛/新德里时钟、工作状态、服务代理及命令行终端。
- `apps/diet/`（网页中已不显示）：饮食日记、按日期查看、折叠餐食、DeepSeek 自然语言查询及修改。日记日期按 UTC+0 划分（北京时间 08:00 换日），跨北京时间零点的夜班记在同一天；时钟、警报时间和比特币当日涨跌仍用北京时间。已有记录的日期保持不变。
- `apps/bitcoin/`：欧易/币安只读账户查询、离线钱包、价格警报、定投成本和长期持仓浮盈。
- `cloud/`：Cloudflare Worker 云端终端（D1 数据、登录、定时同步、快速出境），部署与迁移见 `cloud/README.md`。
- `security_guard/`：本机安全卫士的命令行源码。
- `configs/api-credentials.json`：按仓库所有者明确要求，包含明文欧易、币安及 DeepSeek API 配置。仓库为私有。

## 当前持仓功能

只展示持仓平均买入价、当前 BTC/USDT 价格、浮盈和收益率。每笔定投按实际净到账 BTC 与含手续费支出自动更新移动加权平均成本；后台每 20 秒核算，页面每 30 秒刷新。历史卖出只调整剩余持仓成本。跨币种买入按成交分钟行情折算，计算假设在页面可展开查看。

- **比特币总持有**：欧易 BTC 净持有 + 币安 BTC + 离线钱包。币安计入现货、资金和理财钱包里的 BTC；杠杆、合约钱包可能含借入或保证金，只计入资产估值，不算作持有的 BTC。BTC 数量显示到 8 位小数（聪），完整数值在鼠标悬停提示里。
- **成本账本（含币安）**：云端把币安的 BTC 成交并入同一本成本账本：现货 BTC/USDT、BTC/USDC、BTC/FDUSD 的每笔成交（从第一笔起读取）和闪兑（Convert）。手续费全部计入成本：BTC 手续费从到账数量里扣除，USDT 等计价币手续费加到支出，用 BNB 抵扣的手续费按成交那一分钟的币安价格折算。非 USDT 计价的成交按成交分钟的币安收盘价折成 USDT。只计入欧易账本覆盖起点之后的成交。币安历史全部导入后（首次通常 3 分钟内）才并入，并同时把币安 BTC 计入持仓浮盈和均价，保证成本与持仓始终对应；之后每 5 分钟读取新成交，闪兑每 30 分钟。若某笔币安卖出没有对应的买入记录、无法接上已核对的欧易账本，币安部分暂不并入，欧易账本照常更新，“BTC 定投与成本”旁会显示“币安未并入”并在悬停提示里说明原因。暂不包括 P2P 直接买入 BTC 和银行卡买币。本机（Windows）终端的成本账本仍只读取欧易成交。
- **BTC 定投与成本**：标题旁显示账本包含的交易所（“欧易 + 币安”，或“币安导入中”）。“累计净投入”现在是全部 BTC 买入减卖出回款、按成交时价格折成 USDT 的合计（以前只统计 USDT 计价的成交）；“今日 BTC 买入”也按 USDT 折算计入 USDC 等其他计价的买入。
- **价格变动盈亏**（钱包页，可选今日、近一周、近一个月、近三个月）：只算价格涨跌带来的盈亏，即每段时间持有的 BTC × 这段时间的价格变化；人民币结果包含汇率变化。买入、转入、转出和新计入的钱包只改变持有量，不算盈亏。云端每分钟的余额快照记录累计值，周期结果是“现在 − 周期起点”的差。余额历史还没覆盖到周期起点时显示“—”，悬停可看到原因。
- **累计盈亏**（总览卡片与钱包页）：当前加密资产总市值 + 已提出 − 累计投入，即已实现与未实现盈亏之和，正数绿色、负数红色，旁边是相对累计投入的收益率；投入和提出取自已核对的出入金记录（云端），悬停可看到计算式。本机终端没有这份记录，显示“—”。
- **币安读取**：云端每分钟用只读 API 读取钱包余额（官方 `needBalanceDetail=true` 逐币明细）；若现货或资金钱包没有返回明细，再用这两个钱包各自的只读余额接口补齐。没有逐币明细的其他钱包按钱包合计计入。单个无法识别的条目只把所在钱包标为不完整，不再让整个币安读数失败；中文等无大小写文字的币种代码也能识别。币安读取失败时，钱包页“资产分布”里的“币安”会显示状态，悬停可看到原因（例如 IP 白名单或地区限制）。登录后打开 `/api/cloud-diagnostics` 可看到两家交易所的只读连接、币安余额明细与成交历史能否读取，以及币安成交导入进度（只显示是否成功和条数，不含余额或密钥）。

## 总览

两张卡片并排，高度占满电脑窗口；窗口越高，两张走势图越大（最高约 560 像素）。

- **加密资产**：总估值（美元与人民币），BTC 持仓、持仓均价、BTC 浮盈和累计盈亏四个数字，近 30 天的 BTC 余额走势（不足 30 天时显示实际覆盖的天数，鼠标悬停可看到区间高低），标题旁是今日价格盈亏（北京时间 00:00 起，只算价格涨跌，买入和转账不计入；悬停可看到人民币结果或暂不可用的原因），然后是存放位置、币种分布和“攒到 1 BTC”进度。余额走势包含买入和转入，所以用品牌橙色而不是红绿色绘制。
- **价格警报**：实时价格、当日区间、北京时间当天的价格走势、警报档位和最近警报。

## 钱包页（加密资产 → 钱包走势）

在总终端里是三张卡片，和总览同一种样式：

- **左：比特币总持有**。BTC 总数和人民币、美元市值，右侧是价格变动盈亏（可选今日、近一周、近一个月、近三个月）；下面一行是离线钱包、欧易、币安各自的 BTC；四个数字块：累计盈亏、持仓浮盈、收益率、持仓平均买入价，下面一行是 BTC 和总加密资产的平均年化；然后是合计余额走势（人民币、美元或 BTC，今日、30D、90D 或全部），走势图占满卡片剩余的高度，鼠标悬停时在左上角显示该点的时间和金额；最后是“攒到 1 BTC”进度。
- **右上：资产分布**。美元、人民币和 BTC 三种计价的总额，按币种或按存放位置切换，环形图和前 4 个币种（其余合并为“其他 N 种”）。“币安连接”以浮层打开。
- **右下：定投日记**，卡片底部是累计净投入、现货净买入和今日 BTC 买入（对比每日计划）。

当前价格、逐年回测、计算说明、链上地址视图和欧易连接卡片在这里不显示；单独打开比特币终端（`/btc/`）仍显示全部明细。

## 定投日记（加密资产 → 钱包走势，右栏“资产分布”下方）

像 GitHub 个人主页的贡献图：每一列是一周（周一到周日），每个方块是一天（按北京时间计日），从 2024-12-14 首笔买入开始。当天投入越多，方块的橙色越深；灰色是没有买入。

- 颜色分六档，按当天投入的 USDT 和“通常一天”（所有买入日的中位数，例如每天 20 USDT 的定投）比较：不到一半最浅，通常的一天在正中间（第 3 档），1.5 倍、3 倍、6 倍以上依次加深：浅色模式下第 4 档是比特币橙（#f7931a），再往上是更深的橙；深色模式下从暗棕到亮橙，投入越多越亮。以 20 USDT 为例，分界约为 10、18、30、60、120 USDT，悬停图例可看到实际分界。标尺由首笔以来所有买入日决定，所以同一天在“近一年”和各年份里颜色一致；没有 USDT 价格的买入按其他买入日的中位成交价估算。
- 右上角可切换“近一年”和各年份（2026、2025、2024）。标题旁是首笔以来的买入天数和 BTC 合计；下面一行是所选范围的买入天数、BTC、最长连续和当前连续买入天数（今天还没买入不算中断），约合多少 USDT 在这一行的悬停提示里；颜色图例在同一行右侧。
- 鼠标悬停方块显示日期、当天买入的 BTC、约合 USDT 和成交笔数；键盘可用方向键逐日查看。手机上可左右滑动，默认显示最近几周。
- **全部定投记录**：点一下定投日记（标题、说明行或任一方块；手机上轻点方块），页面上方会打开“定投记录”：每个买入日一行，从新到旧，列出日期、买入的 BTC、投入的 USDT、当天的成交均价和笔数，行首的小方块是那天的颜色；点的是方块就直接翻到那一天并高亮。顶部可选“全部”或某一年，下面一行是所选范围的天数、笔数、BTC、USDT 合计和平均成交价。记录按窗口高度分页，不会滚动：用“较新 / 较早”按钮、方向键、PageUp/PageDown、Home/End、鼠标滚轮或手机上滑动翻页；按 Esc、点右上角 × 或点外面关闭。页面布局不变。
- 数据和“BTC 定投与成本”是同一本账：计入实际净到账的 BTC（已扣除 BTC 手续费），USDC 等其他计价按成交那一分钟的价格折成 USDT；币安的成交只在并入成本账本后计入；卖出不算定投。账本里如果有早于 2024-12-14 的买入，起点会提前到那一天，不会被隐藏；账本覆盖起点晚于首笔买入时，未覆盖的日期显示为斜纹（单独打开比特币终端时另有文字说明）。
- 云端接口 `/api/wallet/btc-dca-diary`（只读），只在成本账本变化后才重新统计。本机终端用本机账本（只有欧易），非 USDT 计价的买入当天不显示 USDT 金额。

## 本机运行

需要 Windows、Python 3.9+、Node.js 20+，比特币后台依赖见 `apps/bitcoin/requirements.txt`。

```powershell
python -m pip install -r apps/bitcoin/requirements.txt
python restore_api_credentials.py
$env:XHY_DIET_ROOT = Join-Path $PWD 'apps/diet'
$env:XHY_OPTIONS_ROOT = Join-Path $PWD 'apps/bitcoin'
python launch.py
```

总终端默认地址为 http://127.0.0.1:8780/；饮食和比特币后台分别使用 4173、8766。CMD 使用 `python cli.py`，或双击原有启动脚本。上述环境变量让启动器使用仓库内的两个子项目。

## 一屏显示，不用滚动

每个页面都正好占满一个窗口，任何地方都不出现滚动条：总终端和各嵌入页面本身都不能滚动，总览的两张走势图、钱包页的余额走势和资产分布会随窗口高度伸缩；窗口再小（例如 Windows 缩放 150% 时 Chrome 只有约 1280×555 的页面区域），页面会整体略微缩小（最小 70%）而不是出现滚动条，窗口变大后自动恢复。已在 1024×540 到 2560×1300 的 12 种窗口和三种手机尺寸上逐页检查：没有滚动条，也没有内容被截掉；数据读取失败时同样如此。

- 电脑：总览、价格警报、钱包走势和快速出境都在一屏内。快速出境左边是出发条件（三列紧凑排列），右边是出发方案。
- 手机（以及宽度不足 1000 像素的窗口）：内容放不下一屏的页面分成几部分，在页面顶部切换：价格警报分“行情 · 警报 · 邮件”，钱包走势分“持仓 · 分布 · 定投”（定投里是定投日记和定投与成本，日记默认显示最近几周，可左右滑动），快速出境分“出发地 · 条件 · 方案”（“比较直飞方案”按钮始终在底部，查询完成后自动切到方案）。手机总览只保留价格卡片和资产卡片的主要内容，存放位置、币种分布、攒到 1 BTC 和最近警报在加密资产页查看。
- 资产分布只列市值最大的 4 个币种，其余合并为“其他 N 种”（悬停可看到每个币种和市值），总览的币种分布同理只列前 3 个。各面板自己的“刷新”按钮在总终端里省去（数据会自动刷新，页头的重新加载按钮仍可用）。

## 不显示提示信息

总终端只显示数字和操作，不显示提示文字：连接状态、同步中、暂不可用、等待快照、说明文字、空状态（如“暂无警报”）、页脚时间和图表说明都不出现。数据是否最新看页头的同步圆点（连接详情在点击后的弹层里）；还没读到的数字显示为“—”。自己操作的结果仍会显示：保存警报设置、邮件设置或币安连接后，结果显示几秒；在出境页面定位或查询航班失败时，原因显示在表单里。单独打开比特币终端（`/btc/`）或出境页面时，原有的提示和说明都还在。

## 手机界面

打开页面时自动识别设备：手机（iPhone、Android 手机，或短边小于 600px 的触屏设备）显示手机界面：页头第一行是 ~/xhy、页面标签（总览 · 资产 · 出境）、同步状态、刷新和明暗按钮，第二行是可横向滑动的时间条；连接详情从底部弹出。电脑和 iPad 显示桌面界面。连接详情里的“界面”可切换为自动、手机或电脑，选择保存在当前浏览器；也可以在地址后加 `?ui=mobile`、`?ui=desktop` 或 `?ui=auto`。添加到 iPhone 主屏幕后以全屏方式打开。

## 时钟与工作状态

- 页头以丹佛时间和当地日期为主，依次显示丹佛、北京、GMT、新德里时间；丹佛使用 `America/Denver`，自动跟随当地夏冬令时。鼠标悬停可看到各地日期和时差。
- 工作时间固定为丹佛当地周一至周五 09:00–17:00。工作状态、周末判断和距开工/下班倒计时均按丹佛当地日历计算，跨夏冬令时的周末也按实际经过时间倒计时，无需手动切换班次。换算到北京时间，夏令时为 23:00–次日 07:00，冬令时为次日 00:00–08:00。
- CMD 客户端页头同样显示这四个时间和当前班次状态。

## 实时行情与快捷操作

- 总览页的比特币价格、当日涨跌、区间和走势末端随行情更新（本机每秒，云端约每 5 秒），卡片标题旁显示“实时”，浏览器标签页标题同步显示价格。数据流只含行情、警报设置和最近 8 条警报，不含整日走势（`/btc/api/terminal/events?view=market`）；离开总览或标签页隐藏 5 分钟后断开，回来自动重连。本机比特币终端自身的数据流在走势不变时只发送最新的点。
- 价格走势按北京时间当天每分钟一个真实价格绘制（最多约 4 分钟一个点）。云端若有时段没有采样（后台某次同步失败、刚到新的一天、刚部署），每分钟的后台同步和打开页面时会用币安（不可用时用欧易）的 5 分钟 K 线收盘价补上，最多每 5 分钟补一次；补的点不会覆盖实时采样。迟到或过期的行情只占它自己的那一分钟，不再删掉之后的采样（以前这会让走势变成一条直线）。本机终端每 10 分钟检查一次走势缺口（例如电脑睡眠后），同样用 5 分钟 K 线补齐。
- 电脑上按 ⌘K / Ctrl+K（或 `/`、`?`）打开命令面板，可按中文、英文或拼音首字母搜索页面和操作；`1` `2` `3` 切换页面，`R` 刷新总览，`T` 切换明暗。焦点在嵌入的项目页面内时同样有效，输入文字时不触发。连接详情底部列出这些按键。
- 在本机打开时，若比特币终端未运行，总览顶部和对应页面显示“启动服务”按钮，一键在本机启动，恢复后页面自动重新加载。

## 云端终端

正式终端也运行在 Cloudflare Worker 上（需登录，不依赖电脑开机），见 `cloud/README.md`。本机和云端使用同一套 `frontend/`：

- 本机（127.0.0.1 / localhost）可从网页启动未运行的服务；云端由 Worker 提供全部接口，不显示“启动服务”。
- 快速出境的航班数据源和出行设置保存在云端数据库，只在云端终端中使用。宽屏时左边是出发条件（出发地、时间与证件、目的地国家），右边是出发方案和购票入口；手机上依次排列。页面右上角显示航班数据源状态，“航班数据设置”以弹出面板填写 API key，点击面板外或按 Esc 关闭。
- 登录页与终端使用同一套配色，跟随你上次选择的明暗模式。
- 云端登录有效期 7 天。过期后，打开着的页面会在下一次刷新（一分钟内，或切回该标签页时）自动转到登录页，登录后回到原来的页面，不会一直显示过期数据。
- 地址后加 `?demo` 显示标注为“演示数据”的示例数据，不读取任何账户，可用于预览界面。

- 比特币：从原项目恢复 `terminal/data/`，特别是 `bitcoin-balance-snapshot.json` 和 `bitcoin-cny-rates.json`；在 `apps/bitcoin/` 内运行 `node terminal/wallet/build_wallet.mjs` 重新生成余额页面。生成页含私人快照，因此不纳入 Git。
- DPAPI 受保护的账本与凭据绑定 Windows 用户。跨电脑时可用本仓库的明文 API 配置重新写入凭据，历史账本仍需按原导入流程恢复，不会伪造历史成本。
- 邮件凭据没有包含；如需邮件通知，在本机页面重新配置。

`restore_api_credentials.py` 只把本仓库的 API 配置导入仓库内比特币项目的本机加密存储；已有凭据不会覆盖，不调用交易或转账接口。
